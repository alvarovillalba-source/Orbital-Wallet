Creá guías visuales con estilo Orbital

Importá una guía HTML terminada o documentos de referencia, organizá el contenido por secciones, ajustá las capturas y exportá una página independiente con navegación, edición, zoom de imágenes e impresión a PDF.

1. Importar archivos o URL

Elegí un archivo o una página pública HTTPS para editarla antes de publicarla.

⇧
Arrastrá tus documentos aquí

DOCX, PDF, TXT, HTML, PNG, JPG y WEBP

Listo para importar. Los documentos se procesan localmente.

2. Cómo se organiza

Las guías HTML con secciones conservan su orden, navegación, capturas y notas. Cada sección puede editarse como unidad y también podés agregar texto, imágenes o nuevas secciones.

Secciones y navegaciónConservá el índice y reordená el contenido.
Capturas adaptablesLas imágenes se ajustan sin desbordar ni superponerse.
Guía independienteExportá HTML con zoom, edición e impresión.

Nota: la fidelidad depende del archivo. Los PDF se importan como texto extraíble; los escaneados requieren OCR. Los HTML de Orbital conservan mejor su estructura e imágenes.

Editor de la guía

Seleccioná texto o una imagen para editar

Seleccioná una imagen para cambiar su tamaño con el control “Imagen” o el tirador rosa. En imágenes dentro del texto, arrastrala para cambiar su posición; en imágenes independientes, usá los controles Img ← / Img ↔ / Img → y las flechas del bloque.
